Quem somos

A Event Business School é a escola de Adriana CheiraFesta para profissionais de eventos. Para qualquer questão sobre privacidade, escreve para ola@cheirafesta.pt.

A aplicação EBS Uploads YouTube

A aplicação EBS Uploads YouTube é uma ferramenta interna, usada apenas pela Event Business School para publicar e organizar os vídeos do seu próprio canal do YouTube (por exemplo, as gravações das aulas).

Com a autorização da titular do canal, a aplicação acede à API do YouTube para carregar vídeos, editar os seus títulos, descrições e playlists, e ler informação básica do canal. Não acede a dados de outras pessoas nem de outros canais.

Que dados usamos e como

  • Os dados obtidos através das APIs Google servem só para gerir o canal da Event Business School.
  • Não vendemos, não partilhamos e não transferimos estes dados a terceiros.
  • As credenciais de acesso ficam guardadas de forma privada, num computador da Event Business School.
  • O uso de informação recebida das APIs Google cumpre a Política de Dados do Utilizador dos Serviços de API Google, incluindo os requisitos de uso limitado.

Como retirar a autorização

A autorização pode ser retirada a qualquer momento em myaccount.google.com/permissions. Para pedir o apagamento de dados, escreve para ola@cheirafesta.pt.
